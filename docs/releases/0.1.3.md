# Release 0.1.3 – Mobile Drawer, CAD-Texte und Site-Banner

Datum: 24. August 2026

## Ergebnis

Der bisher dauerhaft sichtbare untere Bedienbereich ist jetzt ein mobiler Bottom-Drawer. Er kann vollständig nach unten ausgeblendet und über eine freistehende Taste wieder geöffnet werden. Dateiimport, aktuelle DWG, Objektauswahl, Standortinformationen und Hinweise bleiben zusammen in diesem wiederverwendbaren Bereich.

Eine neue Kartenaktion blendet sämtliche CAD-Texte unabhängig von ihrer Layerzuordnung gemeinsam aus und wieder ein. Andere CAD-Geometrien bleiben unverändert sichtbar.

Das Web Component `site-info-banner` 1.1.0 zeigt Copyright, Anwendungsversion und den GitHub-Link. Im freien Kartenmodus überdeckt es weder Drawer-Taste noch Geoportail-Attribution. Geöffnete Bottom-Drawer dürfen den Banner bewusst überlagern.

## DWG-Kompatibilität

Der Import versucht weiterhin zuerst, erweiterte LibreDWG-HATCH-Begrenzungen zu übernehmen. Falls parserinterne Rohdaten einer Zeichnung nicht aus dem Worker übertragen werden können, erfolgt automatisch ein zweiter lokaler Import ohne diese Zusatzdaten. Dadurch bleiben kompatible Schraffuren verfügbar, ohne ältere DWG-Dateien vom Import auszuschließen.

## Abnahme

- 15 Vitest-Tests bestanden
- TypeScript- und Vite-Produktionsbuild bestanden
- 390 × 844 Pixel ohne Seitenüberlauf geprüft
- Drawer geöffnet, geschlossen und wieder geöffnet
- Banner, Attribution und Drawer-Taste im geschlossenen Zustand überlappungsfrei
- CAD-Textschalter mit realer DWG geprüft
- keine Test-DWG ins Repository aufgenommen oder an einen externen Dateidienst übertragen
