# Release 0.2.4 – Netlify-TypeScript-Build

Veröffentlicht am 26. August 2026.

## Ergebnis

Version 0.2.4 behebt den fehlgeschlagenen Netlify-Build von Version 0.2.3. Die betroffene MLeader-Testfixture liefert die sechs Byte lange `AC1015`-Signatur nun als explizit erzeugten `ArrayBuffer`.

`Uint8Array.buffer` wird in der Netlify-TypeScript-Umgebung als `ArrayBufferLike` typisiert und kann damit theoretisch auch ein `SharedArrayBuffer` sein. Die Normalisierungsfunktion akzeptiert absichtlich nur `ArrayBuffer` oder `Uint8Array`; der strengere Build hat deshalb die vorherige Testzeile abgelehnt. Der neue Fixture-Helfer erzeugt den Puffer direkt und befüllt ihn anschließend über eine Byteansicht.

## Umfang

- keine Änderung an der DWG-Laufzeitverarbeitung
- keine Änderung an MLightCAD, OpenLayers, Kartenbindung oder Sichtbarkeitslogik
- keine neue Abhängigkeit, Route, Worker- oder WASM-Datei
- keine Änderung der Drittanbieterlizenzen

## Prüfung

- vollständige Suite: 19 Testdateien und 78 Tests bestanden; davon 14 fokussierte Encoding-Tests
- `npm run build`: TypeScript- und Vite-Produktionsbuild erfolgreich
- die bekannte Vite-Größenwarnung des lazy geladenen MLightCAD-Chunks bleibt unverändert und ist kein Buildfehler

Der Push auf `main` startet weiterhin ausschließlich den vorhandenen Git-basierten Netlify-Build; es erfolgt kein manueller Deploy.
