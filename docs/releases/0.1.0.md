# Release 0.1.0

Datum: 24. August 2026

## Umfang

Erster technischer Prototyp für eine browserlokale LUREF-DWG über dem Geoportail-Orthofoto. Die Version dient zur Prüfung von Kartenintegration, DWG-Normalisierung, mobiler Bedienung und Live-Standort, bevor über eine native beziehungsweise Expo-basierte App entschieden wird.

## Build

```sh
npm ci
npm test
npm run build
```

Auslieferungsordner: `dist/`.

## Bekannte Grenzen

- reale LUREF-DWG noch nicht abgenommen
- Splines werden in 0.1.0 über vorhandene Fit-/Kontrollpunkte angenähert
- keine Xrefs, Papierlayouts oder 3D-Darstellung
- große Zeichnungen können je nach Mobilgerät den verfügbaren Arbeitsspeicher überschreiten
- das Haupt-JavaScript-Bundle ist wegen OpenLayers und CAD-Parser größer als 500 kB; Code-Splitting ist eine spätere Optimierung

## Rollback

Da keine Datenbank und keine Migration existieren, besteht ein Rollback ausschließlich aus dem erneuten Veröffentlichen des vorherigen statischen Deploys.
