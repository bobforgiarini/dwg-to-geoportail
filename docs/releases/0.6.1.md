# Release 0.6.1 – kompakte Messbedienung

## Ergebnis

Die Distanzmessung verwendet weiterhin denselben gemeinsamen `BottomSheet` wie Layer und Blöcke, ist jetzt aber auf Mobilgeräten auf das tatsächlich benötigte Minimum reduziert. Ohne sichtbaren Titel, Anleitung, Punktkoordinaten oder Snap-Detailmeldung enthält der Sheet nur:

- CAD-Snap
- die aktuelle Punktaktion
- nach der zweiten Punktwahl das Distanzresultat

Die Aktionszeile besitzt weiterhin mindestens 44 CSS-Pixel große Touchziele. Das gemeinsame Safe-Area-Padding liegt direkt am unteren Rand; ein eigenes Höhenlimit, das den unteren Button auf kleinen Geräten abschneiden konnte, wurde entfernt.

## Mobile und Desktop

Touchgeräte behalten bewusst die sichere Aim-Bedienung: Karte beziehungsweise CAD werden unter dem festen roten Kreuz ausgerichtet und ein Punkt wird ausschließlich über die Aktion im Sheet gesetzt. Touch-Tap, Pan und Pinch erzeugen keinen Messpunkt.

Auf Desktop steht zusätzlich eine direkte Mausbedienung bereit:

- Hover zeigt einen gültigen sichtbaren CAD-Snap am Mauszeiger.
- Ein kurzer Mausklick setzt den nächsten Punkt an dieser Position.
- Eine Dragbewegung bleibt Navigation und wird nicht als Punkt interpretiert.
- Ohne DWG kann auch die reine Geoportail-Karte direkt angeklickt werden.

OpenLayers verwendet weiterhin den auf 48 Features und 512 Segmente begrenzten 18-Pixel-Snap. MLightCAD verwendet denselben Fangradius über den nativen OSNAP und respektiert Layer-, Block-, Text-, Objekt- sowie Reorder-Sichtbarkeit. Hover- und Klickarbeit bleibt vollständig außerhalb der synchronen CAD-Kamerabrücke.

## Datenschutz und Grenzen

DWG-Dateien und Messpunkte bleiben im lokalen Sitzungsspeicher. Es wurden keine API, Datenbank, Dateiübertragung oder persistente Speicherung ergänzt. Die Messung bleibt auf ebene LUREF-Distanzen in `EPSG:2169` beschränkt.

Eine responsive Browserprüfung ersetzt weiterhin keine Abnahme auf echtem iPhone-Safari. Insbesondere Safe Area, Touch-Pan und die explizite Punktaktion müssen vor Veröffentlichung zusätzlich auf realer Hardware geprüft werden.

## Verifizierung

- 52 Vitest-Dateien mit 288 bestandenen Tests
- erfolgreicher TypeScript-/Vite-Produktionsbuild
- responsive Browserprüfung bei 390 × 844 CSS-Pixeln: 98 Pixel Gesamthöhe, 44-Pixel-Aktionen, vollständiger unterer Safe-Area-Abschluss und kein Seitenoverflow
- Desktop-Browserprüfung ohne DWG: zwei direkte Mausklicks setzen beide LUREF-Punkte und schließen die Distanzmessung fehlerfrei ab
